저탄수 30일 식단

닭·오리 제외 · 가공식품 제외 · 점심 배달 / 저녁 15분 요리 · 하루 2끼 · 메뉴 풀 50개 중 30일 로테이션
방법 1 · 캘린더 알림 (.ics) — 추천
아이폰 기본 캘린더로 매일 정해진 시간에 오늘 점심/저녁 메뉴가 알림으로 뜹니다. 앱 설치 없음.
  1. 아이폰 Safari에서 이 페이지를 열고(아티팩트 안에서 다운로드가 막히면 "새 창에서 열기") 다운로드
  2. 파일 앱 → .ics 탭 → 오른쪽 위 "모두 추가" → 캘린더 선택
  3. 알림은 각 이벤트 시작 시각에 울립니다. 시작일을 바꾸거나 초기화하면 다시 내보내기
방법 2 · 단축어 자동화
단축어 → 자동화 → "매일 10:30" → 동작 "URL 열기"에 이 페이지 주소. 정해진 시간에 오늘 탭이 열립니다.
왜 웹 푸시는 안 쓰나
iOS 웹 푸시는 홈화면 추가 + 푸시 서버가 필요해 이 단일 파일로는 불가능합니다. 캘린더 방식이 가장 안정적입니다.
로테이션 규칙
  • 1회차(1~30일): 메뉴 1~30번 순서대로
  • 2회차부터: 직전 회차에 안 나온 20개를 전부 + 나왔던 30개 중 10개만 뽑아 30일을 채우고 순서를 섞음 → 매 회차 최소 20일은 새 메뉴, 한 회차 안에서는 절대 중복 없음
  • 시드 기반이라 시작일만 같으면 어느 기기에서 열어도 같은 결과
매일 고정 베이스 (저녁 곁들임으로 소량)
  • 자연치즈 1장 (격일) → Ca·B2·B12
  • 브라질너트 1개 → 셀레늄 하루치 / 호두 2개 → 오메가3(ALA) / 아몬드 5개·호박씨 → 비타민E·Mg·Zn
  • 방울토마토·파프리카·블루베리·망고 한 줌 → 비타민C·A (소량 로테이션)
  • 김 1봉 (또는 미역) → 요오드
  • 들기름 1작은술 → ALA / 김치 한 접시 → 비타민C·프로바이오틱
  • 물 2L
주간 단백질 로테이션
  • 등푸른생선·연어 3회 → 오메가3 EPA/DHA·비타민D·B3·B12
  • 소고기·양고기 2회 → 철·아연·B12·B6
  • 돼지고기 1~2회 → 비타민B1
  • 조개·굴·전복·홍합 1~2회 → 아연·구리·요오드·B12
  • 계란·두부·낫토 날 → 비오틴·콜린·K2·몰리브덴·Ca
  • 잎채소 매일 → K·엽산·Mg·식이섬유
얇은 지점: 비타민D는 생선+계란으로 최소량은 되지만 겨울엔 햇빛 15분 또는 D 보충을 고려. 굴은 10~3월만.
